# Roadmap - Snooker Player 3.0

## Version 0.1 - MesureVision

Objectif :
Créer un prototype permettant de mesurer les distances entre les billes.

Fonctionnalités :

- Connexion à une caméra USB
- Affichage vidéo
- Calibration
- Détection des billes
- Calcul du centre des billes
- Mesure des distances
- Sauvegarde d'une image

État : En développement

---

## Version 0.2

Objectif :
Détecter automatiquement toutes les billes.

Fonctionnalités :

- Détection des 22 billes
- Coordonnées X/Y
- Sauvegarde de l'état de la table
- Comparaison avant/après un coup

---

## Version 0.3

Objectif :
Préparer l'intégration dans Snooker Player.

Fonctionnalités :

- Interface utilisateur
- Gestion des configurations de caméras
- Tests de précision
- Optimisation des performances

---

## Version 1.0 - Snooker Player

Fonctionnalités :

- Comptage des points
- Aide à l'arbitrage
- Détection des fautes
- Repositionnement des billes
- Historique des coups
- Gestion des matchs
